# Security Policy

## Supported Versions

Specifically for the GenAI APAC 2026 Hackathon submission, we support the following versions of this agent:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not open a public issue. Instead, please report it to the project maintainers via the hackathon submission portal or contact the lead developer directly.

We take all security reports seriously and will investigate each one thoroughly.

### Exclusions
Please note that this is a proof-of-concept AI agent built for a hackathon. It relies on third-party LLM APIs (Google Gemini). Vulnerabilities related to the underlying Gemini models should be reported directly to Google Cloud Security.
